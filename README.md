# Gemini 原生端点

**简体中文** | [English](./README.en.md)

为 DeepSeek Harness 添加独立的 Gemini 提供商，使用 Google 官方 Gen AI SDK，支持 Gemini API 及兼容网关。

## 功能

- 流式回复与思考摘要。
- 图片输入、工具调用与对话取消。
- 自定义 API 地址和模型列表，可从提供商获取可用模型。
- 按模型设置上下文长度、输出上限和思考强度。
- 可配置的额度与临时错误自动重试。
- API 密钥由 Harness 凭据服务保存。

## 安装

适用于 **DeepSeek Harness 0.2.x**，最低版本为 **0.2.1-rc.3**。

1. 在 [Releases](https://github.com/AliceRabbit/dsh-gemini-native/releases/latest) 下载 `.tgz` 安装包。
2. 在 Harness 的插件页面安装该文件，并启用插件。
3. 打开 **设置 → 模型 → Gemini → 编辑**，填写 API 密钥。
4. 如需使用兼容网关，在 **自定义设置** 中修改 API 地址，然后保存。
5. 在对话中选择 Gemini 模型即可使用。

默认 API 地址为 `https://generativelanguage.googleapis.com`。每位用户需要提供自己的 API 密钥；密钥输入框留空会保留已有凭据。

## 模型与重试

在 **自定义设置** 中，可以手动添加模型，或点击 **获取可用模型** 后选择要添加的项目。

**额度与临时错误重试** 默认开启：最多重试 **5 次**，等待时间从 **5 秒**递增至 **30 秒**，带随机抖动。次数和等待时间均可调整；关闭后恢复 Harness 默认重试行为。

重试由 Harness 管理，不会额外发送“继续”或从头重跑整轮任务。真正耗尽的额度不一定能通过重试恢复，已经结束的失败轮次也不会自动重新启动。

> 本插件支持图片输入，不提供图片、语音或视频生成。模型可用性和功能取决于你的 API 提供商。

## 可选的防降智组件

插件包内附 **Gemini 防降智**，默认关闭，不改变现有请求。需要时，在插件管理中展开本插件包的组件列表，单独启用它；Gemini 提供商保持启用即可。关闭同一组件开关就会停用，不需要重启 DSH，也不影响提供商、密钥或模型配置。

启用组件后，在 **设置 → 模型提供商 → Gemini → 自定义设置** 中调整 **防护强度**，与其他 Gemini 设置一起保存或取消。关闭组件时，已打开窗口中的强度设置也会自动消失，未保存的强度草稿会清除；已保存的档位保留，重新启用时恢复。不会影响其他 Gemini 设置草稿。

也可通过 Cordis 配置设置 `mode`，例如在现有配置覆盖中合并：

```yaml
- id: gemini-routing-shield
  config:
    mode: probe-only
```

可选值：

- **均衡**（`hybrid`，默认）：保留原方案约 5,000 字符屏障及四个身份探针。
- **轻量**（`probe-only`）：约 220 字符屏障及一个探针，输入成本较低。
- **强化**（`fortress`）：约 6,400 字符屏障及四个探针，输入成本更高。

以上是屏障字符数，不是 token 数，探针和配套规则另计。防护会增加输入 token 和费用，可按使用需求选择档位。

核心策略来自 `fxxk-router 1.0.0`：随机屏障、身份探针与忽略探针的配套规则。这里直接适配 Gemini `contents/parts`，覆盖普通请求和工具续轮，不使用代理，不修改工具返回、思考签名或真实身份说明，也不包含 CC 环境接管、输出清洗、额外重试和监控面板。

开关和强度从**下一次提示词组装**生效；已组装的步骤（即使仍在等待开始）及其重试沿用原快照。防护通过 DSH 系统提示词组装记录，适配器只把已记录的屏障移到请求尾部：模型历史不会逐轮堆积屏障，关闭后新步骤不再包含屏障或配套规则。为保持可重建性，会话日志会记录每步完整的防护文本。
